# VV Team

VV Team is the internal coordination and intelligence layer of the VV Hybrid Universe.

## What It Is

VV Team is a repository for internal-facing coordination, governance and rules surfaces connected to the wider VV system.

It combines team logic, intelligence rules and operational interfaces.

## Why It Exists

The VV Hybrid Universe needs more than public products.

It also needs internal structure for:

- team coordination
- internal logic
- intelligence rules
- operational control

VV Team exists for that layer.

## Repository Scope

This repository currently includes:

- `vv-team-ALL-IN-ONE.html`
- `vv-team-logic-v2.js`
- `vvhi-constitution.js`
- `vvhi-shadow.js`

## Status

Active internal systems repository.

This is not the main public entry product.
It supports the internal side of the VV Hybrid Universe.
